普通

食材を切ったり加熱したりするのは料理の基本だろ、という人向け。

こんにゃくとちくわの甘辛炒め 
- 材料  
    - こんにゃく    1個
    - ちくわ        5本
    - （鶏肉　任意）
    - ごま油
    - (A) 水        50 ml
    - (A) みりん    大さじ1
    - (A) 醤油      大さじ1
    - (A) 酒        大さじ1
    - (A) 味の素    3〜5振り
- 作り方 (火は常に中火)  
    1. 鶏肉を入れる場合は、ごま油で炒めておいて、皿によけておく。
    2. こんにゃくを炒める。細かい泡が出てきて気持ち悪いが、これがなくなるまで炒める。
    3. ちくわを入れてちょっと焦げがつくまで炒める。
    4. 炒めている間に(A)を混ぜておく。
    5. (鶏肉をフライパンに戻し、) (A)を加える。
    6. 水分がある程度飛んだら出来上がり。

難しい

休日だし気合い入れてみるか、という人向け。
